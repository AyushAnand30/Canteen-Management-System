# Canteen-Management-System 
🥗 Smart Campus Canteen – Frontend Web App
Welcome to our hackathon project: a Smart Canteen Web App designed for modern educational campuses. This fully frontend solution provides a seamless digital menu, pre-order experience, and simulated payment—all to reduce cafeteria wait times, improve transparency, and enhance student satisfaction.

🚀 Built as part of the XiBit Hackathon 2025.

📸 Project Preview
Add screenshots/gifs here if possible

🛠 Features
✅ Student Login (with OTP flow)
✅ Modern Home Dashboard
✅ Live Canteen Menu (veg/non-veg + pricing)
✅ "Add to Tray" functionality with total price calculation
✅ Fake QR Code Generation for Simulated Payment
✅ Mobile-Responsive Design
✅ Fully Frontend — No Backend Required

🧩 Pages & Flow
🔐 Login Page

Enter Roll No / Email

Redirects to OTP Page

🔑 OTP Page

Simulates 4-digit OTP input

On submit, redirects to Home

🏠 Home Page

Welcome user

Navigate to menu and profile

🧾 Menu Page

Displays categorized items (e.g. Breakfast, Lunch)

Filter by veg/non-veg

“Add” items to tray and dynamically show total

💳 Payment Page

Shows fake QR Code

Simulates digital payment (e.g., UPI QR)

Displays confirmation message

🧪 Tech Stack
HTML5 + CSS3

JavaScript (ES6)


localStorage for cart state

 Netlify for deployment
